# ADR 0050: Instrument Memory-Service Plugboard Calls by Subclassing the Graphiti LLM Client; Unified `plugboard_*` Metric Family Across Processes

**Status:** Accepted — 2026-06-08

**Context.** The memory service is the largest plugboard amplifier: Graphiti's `add_episode` fans out into many Haiku calls (entity/edge extraction, dedup, temporal resolution). But Graphiti owns the LLM client and calls it internally, so we don't control those call sites. The memory service is a separate process with no `prometheus-client` dependency and no `/metrics` endpoint today. We must attribute per-call (and ideally per-token) volume for both the OSS `DefaultLLMClient` and the Meta `MetaMemoryLLMClient` without forking the Meta overlay.

**Decision.** Add an `InstrumentedAnthropicClient` subclass of Graphiti's `AnthropicClient` in a new `src/memory/memory/instrumentation.py`, and wrap the returned client in `create_llm_client` (`src/memory/memory/llm.py`). Both client variants return a Graphiti `AnthropicClient` via `.client`, so wrapping at `create_llm_client` covers both with **zero** workbench-meta changes. Override the generate method to record **calls/latency/errors authoritatively and tokens best-effort** (the exact method name and whether the pinned `graphiti_core` surfaces `usage` is verified at implementation time; the design degrades to calls/latency only if tokens aren't accessible). Emit the **same `plugboard_*` metric family** as the main app with `client="memory"` (unified for uniform Grafana queries; Prometheus also adds `job`/`instance` per scrape target), plus episode-level `memory_episodes_ingested_total{type}` where `type ∈ {triage, decision, entity}`. The `triage`/`decision` counters are incremented in `_run_ingestion_worker` (keyed by `entry.type`), but `entity` recording **bypasses the worker** — `record_entity` is a synchronous request handler that calls `layer.record_entity` directly — so `type=entity` is incremented in that handler, not the worker (instrumenting only the worker would leave `type=entity` permanently at zero). Add `prometheus-client` to `src/memory/pyproject.toml`, a memory-scoped registry, and an unauthenticated `/metrics` endpoint. Edit only `src/memory/memory/`, never the stale `build/` copies.

**Consequences / Alternatives.** This seam choice shapes where all memory LLM metrics live and how the Meta overlay inherits them, so it earns an ADR. We rejected (a) httpx event hooks as the primary mechanism — the OSS `DefaultLLMClient` lets `AnthropicClient` build its own internal httpx client, leaving no uniform injection seam; (b) layer-only instrumentation (`record_*`/`query_*`) — gives episode counts but cannot see Graphiti's internal LLM fan-out or tokens. We do not attempt an `operation` label (extract_nodes/edges/dedupe) in v1 — it requires Graphiti-version-fragile introspection; a single implicit operation keeps cardinality safe. Tokens are explicitly best-effort and documented. With ADR 0048's drop-gating upstream, decision-episode volume reaching the memory service falls, making `memory_episodes_ingested_total{type=decision}` the visible reduction signal.
